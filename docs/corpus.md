# Compatibility corpus

`tests/corpus` holds the repository's own office samples, generated from
synthetic Turkish content by our own writers. Every file is listed in
`tests/corpus/manifest.json`, and `crates/officecore/tests/corpus_test.rs`
imports each one through the reader the manifest names.

## What the corpus proves

* the writers and readers agree on the formats this repository produces
  (round-trip import of docx, odt, xlsx, pptx and UDF output),
* every sample keeps importing after importer changes (a regression fails CI),
* the committed files stay in sync with the manifest (orphan or dangling files
  fail CI),
* the content is original and free of personal data, so the files can live in
  this repository.

## What it does not prove

The corpus is generated by our own writers, so it says nothing about files
produced by *other* applications. Real-world compatibility still needs
third-party samples, which cannot be committed here:

| Source | Format | Used for |
| --- | --- | --- |
| UYAP (Turkish judiciary) | `.udf` | UDF import - still unverified against a real file |
| KEP providers | `.eml` | KEP import (`tests/fixtures/kep-ornek.eml` covers a simplified case) |
| Banks / e-Fatura portal | UBL `.xml` | invoice import - real portal output still unverified |
| Microsoft Office | `.docx` / `.xlsx` / `.pptx` | import of Office-authored files |
| LibreOffice | `.odt` / `.ods` / `.odp` | import of LibreOffice-authored files |

If you have a sample you can share without personal data, open an issue; do
not commit files you cannot redistribute.

## Layout

Each manifest entry has:

| Field | Meaning |
| --- | --- |
| `file` | path relative to `tests/corpus` |
| `format` / `kind` | `docx`, `odt`, `xlsx`, `pptx`, `udf` / `writer`, `calc`, `impress` |
| `reader` | the Rust reader the corpus test calls |
| `origin` / `license` | where the file comes from (generator, MIT) |
| `content` | the guarantee that the content is synthetic (no personal data) |
| `notes` | what the sample exercises |

## Regenerating

```powershell
cargo run -p officecore --example make-corpus
```

This rewrites `tests/corpus/*` and `manifest.json`. Run the corpus test after
any change:

```powershell
cargo test -p officecore --test corpus_test
```

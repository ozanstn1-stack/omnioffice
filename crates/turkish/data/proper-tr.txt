# Curated Turkish proper nouns for the spell checker (OmniOffice, MIT).
#
# The vendored zemberek lists (proper-from-corpus.dict) only carry derived
# forms ("Ankaragücü", "İstanbulboğazı"); the plain names live in their binary
# lexicon, which this project does not load. This list covers the realistic
# cases: the 81 provinces, common countries and languages, frequent given
# names and the institutions whose names are not acronyms. One entry per line;
# multi-word names are deliberately left out (the checker tokenizes on spaces).
#

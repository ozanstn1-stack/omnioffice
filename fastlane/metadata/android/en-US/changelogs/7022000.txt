7.22.0: Each composite font is read once per document, not once per note: N-up imposition now remembers each /DA font's /ToUnicode, /Encoding CMap, /CIDToGIDMap and /W for the length of one imposition call. A refusal is remembered as well, so a font that cannot be used is not re-read for every note either. The memory the cache may hold is capped; a font that would take it past the cap is used but not stored. The output is byte-identical to before.

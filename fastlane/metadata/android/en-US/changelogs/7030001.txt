7.30.1: A permission restriction now actually binds: a PDF reader verifies the owner password before the user password, so an owner password that is empty or equal to the user password makes whoever opens the file its owner as well - and every permission the file declares becomes advisory. The security screen sent the user password as the owner whenever that field was left blank, which is how a file is normally protected, so "cannot be copied" was often not true.

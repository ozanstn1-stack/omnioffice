7.3.0: Contained worker child (E2.2, #550): the untrusted-document parser child is now contained before it executes. On Windows it is created suspended, assigned to a job object with a 1.5 GiB process-memory limit and only then resumed (the old code assigned the job after spawn), with the suspended thread resumed by thread id; Linux/macOS install RLIMIT_AS and RLIMIT_CPU between fork and exec.

7.30.4: Filling a checkbox with a state the document does not declare is refused: the fill used to write the first declared state and continue, so the file ended up with a /V that claimed one thing while /AS named a state with no appearance stream - a control that renders blank, or shows a state the document does not hold (ISO 32000-1 12.5.5, Table 168). The call now returns an error and writes nothing, for checkboxes and radio groups alike.
